## 5 · Verification — the byte-check belt

| Command | Scope |
|---|---|
| `npm run tokens:check` (root) | `node scripts/tokens/build.mjs --check` — regenerates `tokens.generated.css` / `tokens.generated.ts` and byte-compares against the committed files; **also verifies the RN brand port**: `apps/mobile/src/brand/{mark,lockups,wordmark.generated}.ts` must be byte-identical to `frontend/src/brand/*` |
| `npm run tokens:check -w apps/mobile` | the token check **plus** `icons:check` → `node scripts/brand/build-app-icons.mjs --check` — regenerates every mobile PNG + `shared/brand/mark.svg` and byte-compares against the committed bytes; **exit 1 on drift** |
| `npm run test -w frontend` (includes `tests/unit/r323-brand-system.test.ts`) | the unit belt: (a) the copper-clean scanner — no off-palette hexes (`#B57438`/`#E9B44C`) under `frontend/src` / `frontend/public` / `frontend/index.html`; (c) the generated statics carry the `mark.ts` geometry — miter joins, the one `#FA3600` keystone, no `<linearGradient>` — and stay **byte-pinned** to `mark.ts` + `lockups.ts` |

Regenerate-and-compare is the discipline: after any change to `mark.ts`
(**both copies**), `lockups.ts`, the fonts, or the wordmark script, re-run the
generators in order — `wordmark-build-r323.mjs` → `brand-assets.mjs` →
`build-app-icons.mjs` — then `tokens:check` on both sides and the frontend unit
belt.

## 6 · OLD → NEW renames (the Madarek → TADMORA map)

Two public brand filenames change with the rebrand:

| Old (Madarek era) | New (TADMORA) |
|---|---|
| `frontend/public/brand/madarek-mark.svg` | `frontend/public/brand/tadmora-mark.svg` |
| `frontend/public/brand/madarek-og.jpg` | `frontend/public/brand/tadmora-og.jpg` |

### 6.1 The reference-update requirement

The rename is **not done** until every reference to the old filenames is updated.
Known reference sites (verified in this repo) — each must move to the new
filename in the same change:

| File | Reference |
|---|---|
| `backend/prisma/seed.ts` | `posterUrl: '/brand/madarek-mark.svg'` (lecture posters) |
| `backend/prisma/seed-pilot.ts` | same seeded poster path |
| `backend/prisma/seed-demo-r330.ts` | same seeded poster path |
| `frontend/index.html` | `og:image` and `twitter:image` meta → `/brand/tadmora-og.jpg`; the **schema.org JSON-LD** `"logo"` → `…/brand/tadmora-mark.svg` |
| `frontend/public/sw.js` | the service-worker **precache list** — `/brand/madarek-mark.svg` must become `/brand/tadmora-mark.svg` (a stale entry precaches a 404) |
| `frontend/tests/unit/r323-brand-system.test.ts` | the byte-pin reads `public/brand/madarek-mark.svg` — retarget to `tadmora-mark.svg` |
| `frontend/tests/unit/legal-pages.test.tsx` | asserts the JSON-LD carries `madarek-mark.svg` |
| `frontend/tests/unit/assets.test.ts` | the keeper list (`madarek-og.jpg`, `madarek-mark.svg`) |
| `frontend/tests/e2e/lecture-poster-geometry.e2e.ts` | the seeded `posterUrl: '/brand/madarek-mark.svg'` fixture |
| `backend/tests/modules/curriculum-logic.test.ts` | the sanctioned-media-URL allowlist |
| `apps/mobile/app/owner/content.tsx` | the asset list entry `madarek-mark.svg` |
| `scripts/r323/brand-assets.mjs` | the generator's own output paths (`writeFileSync` seats) |

Also update in the same pass: `frontend/public/manifest.webmanifest`
(`name`/`short_name` → «تادمورا» seats, §4), the boot plate word and noscript
line in `frontend/index.html` (→ «تادمورا»), and the OG card copy (the Madarek
tagline line is replaced by the TADMORA system line). The generator is the
source — change `scripts/r323/brand-assets.mjs` first, regenerate, then sweep
the references above; `tokens:check` + the unit belt catch anything missed.

## 7 · Regeneration quick reference

```bash
node scripts/r323/wordmark-build-r323.mjs   # wordmark.generated.ts + wordmark.svg
node scripts/r323/brand-assets.mjs          # web statics: tadmora-mark/mark/lockup(+stacked)/favicon/icons/tadmora-og
npm run icons -w apps/mobile                # mobile PNGs + shared/brand/mark.svg
npm run tokens:check                        # root byte-belt
npm run tokens:check -w apps/mobile         # mobile byte-belt (icons:check)
npm run test -w frontend -- r323-brand-system  # the unit belt (vitest)
```
